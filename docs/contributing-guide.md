# Contributing

Search existing issues, use the appropriate template, include acceptance criteria, validation, scope, risk, and rollback, and keep one concern per PR.

Install with `npm install`, copy `.env.example` to `.env`, then run the narrowest applicable checks from `AGENTS.md` (normally lint, tests, and build for TypeScript changes).

Update the applicable canonical file under `specs/` when behavior changes; do not add another spec file.
